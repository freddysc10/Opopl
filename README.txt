OpoPL versión 0.3

Sube index.html, manifest.webmanifest y README.txt a la raíz del repositorio GitHub Pages, sustituyendo los archivos anteriores.

Incluye repaso diario (requiere 3 preguntas guardadas del último tema estudiado) y banco de preguntas para simulacros completos de 40 preguntas (requiere 40 preguntas verificadas por tema).
Los datos se guardan localmente en el navegador. Esta versión no sincroniza entre dispositivos.
