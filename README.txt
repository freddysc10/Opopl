INSTALACIÓN
1. Descarga y descomprime el ZIP.
2. En GitHub abre el repositorio freddysc10/Opopl.
3. Sustituye index.html por el nuevo index.html (mantén manifest.webmanifest).
4. Commit changes.
5. Abre la web en Safari y recarga. Si la PWA conserva caché, ciérrala por completo y vuelve a abrirla.

IMPORTANTE
- Antes de actualizar, exporta una copia desde Registro > Seguridad de tus datos.
- No hay sincronización automática entre dispositivos.
- Esta versión no afirma que el banco completo de 15 temas esté auditado ni incorpora todavía 600 preguntas verificadas. Las preguntas existentes de los temas 1-3 mantienen el estado que figura en cada registro; ese estado no debe interpretarse como certificación jurídica global.
